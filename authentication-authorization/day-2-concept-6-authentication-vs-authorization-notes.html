Authorization

Definition

Authorization is the process of determining what an authenticated user is allowed to access or perform.

The goal is to answer:

What can you do?

Top 5 Interview Questions with Answers

Q1. What is Authentication?

Answer

Authentication is the process of verifying the identity of a user or system using credentials such as passwords, JWT tokens, sessions, or OAuth providers.

Q2. What is Authorization?

Answer

Authorization is the process of determining what resources or actions an authenticated user is permitted to access based on roles and permissions.

Q3. What is the difference between Authentication and Authorization?

Answer

Authentication verifies the identity of a user, while authorization determines what actions that authenticated user can perform. Authentication happens first, followed by authorization.

Q4. Why does Authorization happen after Authentication?

Answer

Authorization depends on the user's identity. The server must first authenticate the user and then determine whether that authenticated user has permission to access the requested resource.

Q5. What is the difference between 401 and 403?

Answer

401 Unauthorized indicates an authentication failure, meaning the user's identity could not be verified. 403 Forbidden indicates an authorization failure, meaning the user is authenticated but does not have permission to perform the requested action.

30-Second Interview Summary

Authentication is the process of verifying a user's identity using credentials such as passwords, JWTs, sessions, or OAuth providers. Authorization determines what resources or actions an authenticated user is allowed to access. Authentication answers "Who are you?", while authorization answers "What can you do?". Authentication failures typically return 401, whereas authorization failures return 403. 🚀
